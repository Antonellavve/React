# Akika — E-commerce Frontend

Frontend de una tienda online desarrollado con React. El proyecto integra catálogo de productos, carrito de compras, autenticación, verificación de usuarios, checkout y consulta de pedidos.

**Demo:** [react-dsr2.vercel.app](https://react-dsr2.vercel.app/)

## Funcionalidades

- Catálogo y navegación por categorías.
- Carrito de compras con persistencia local.
- Registro, inicio de sesión y verificación de cuenta.
- Checkout y creación de pedidos.
- Historial y resumen de órdenes del usuario.
- Interfaz adaptable a distintos tamaños de pantalla.
- Consumo de una API REST propia.

## Tecnologías

- React 18 y Vite
- React Router
- Redux Toolkit y Redux Persist
- Axios
- Formik y Yup
- Styled Components
- Framer Motion

## Ejecutar el proyecto localmente

```bash
git clone https://github.com/Antonellavve/React.git
cd React
npm install
npm run dev
```

La aplicación consume la API publicada en [proyecto-final-back-six.vercel.app](https://proyecto-final-back-six.vercel.app/).
